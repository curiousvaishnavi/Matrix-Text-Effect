# 🟢 Matrix Text Effect

A simple and interactive **Matrix Text Effect** built using **HTML, CSS, and JavaScript**.

When you hover over the text, the original text is replaced with random characters and gradually reveals the actual text, creating a dynamic **Matrix-style decoding effect**.

## ✨ Features

- 🎯 Interactive hover effect
- 🔤 Random characters generated dynamically
- 🟢 Matrix-inspired text animation
- ⚡ Smooth text reveal effect
- 🖥️ Simple and lightweight
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How It Works
The original text is stored in JavaScript.
When the user hovers over the text, random characters are generated.
The map() method iterates through each character.
The iteration variable controls how many characters have been revealed.
Random characters are gradually replaced by the original text.
The effect continues until the complete text is revealed.
